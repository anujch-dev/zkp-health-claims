## 🌟 The Core Problem & Solution

Traditional health insurance claims force patients and hospitals to expose sensitive, unredacted clinical data (diagnoses, procedure codes, prescriptions, and full medical histories) to insurance underwriters. This leads to data breaches, profiling, and systemic HIPAA privacy violations.

**ZK-HealthClaims** re-architects the workflow:
1. **Patient Sovereignty**: Encrypted records stored off-chain (IPFS) with cryptographic hash commitments anchored on-chain. Patients grant and revoke doctor access keys.
2. **Hospital ZK Prover**: Hospitals generate a client-side Zero-Knowledge Proof (Groth16 on BN254) proving:
   - The hospital is an accredited provider (Merkle tree membership, depth 4).
   - The claim is tied to an active, unexpired policy (`claimDate <= policyExpiry`).
   - The procedure is in the covered set and claim amount is within coverage limits (`claimAmount <= maxCoverageLimit`).
   - *Without ever disclosing the diagnosis code, procedure notes, or prescriptions to the insurer.*
3. **Smart Contract Settlement**: `ZKPInsuranceSettlement.sol` verifies the Groth16 pairing on-chain, enforces a deterministic **claim nullifier** to block replay attacks, and automatically disburses escrow funds.

## ⚡ Zero-Knowledge Circuit Pipeline (Slice 3)

### 1. Circuit Specifications
- **Framework**: Circom 2.2.3 & SnarkJS 0.7.5
- **Curve**: BN254 (alt_bn128)
- **Constraints**: 1,960 non-linear constraints, 4,208 total wires
- **Ceremony**: Powers of Tau 14 (16,384 constraint capacity)
- **EVM Verifier Gas**: ~210,000 gas

### 2. Compile Circuit to R1CS & WebAssembly Witness
```bash
cd circuits
npm install
npm run compile
```

### 3. Run Powers of Tau & Groth16 Setup
```bash
npm run setup
```
Exports `Groth16Verifier.sol` directly to `contracts/src/Groth16Verifier.sol`.

### 4. Generate Sample ZK Proof & Calldata
```bash
npm run prove
```
Generates Groth16 proof in ~1.7s and produces `calldata.json` ready for on-chain settlement.

## 🔒 Security & Threat Model Summary

| Threat | Vulnerability | Defense Layer | Countermeasure |
| :--- | :--- | :--- | :--- |
| **Replay Attack** | Double-submitting same claim | Smart Contract | Deterministic `claimNullifier` registered on-chain; second attempt reverts with `ClaimAlreadyNullified` |
| **Tampered Calldata** | Altering claim amount or public signals | Groth16 Verifier | BN254 bilinear pairing check fails; contract reverts with `InvalidProof()` |
| **Unlicensed Clinic** | Fraudulent clinic billing policy | Circom Circuit | 4-level Merkle tree membership proof required against approved hospital root |
| **Data Harvesting** | Insurer profiling medical history | Zero-Knowledge | Diagnosis (ICD-10), notes, and prescriptions are private witnesses (never emitted on-chain) |
| **Expired Policy** | Billing after coverage lapse | Circom Circuit | `LessEqThan(64)` constraint strictly enforces `claimDate <= policyExpiry` |
| **Coverage Cap Exceeded**| Billing above remaining coverage | Circom Circuit | `LessEqThan(64)` constraint strictly enforces `claimAmount <= remainingCoverage` |
